# Yogesh Garg — Portfolio

Personal portfolio of **Yogesh Garg**, Full Stack Developer (.NET 8, React.js, Azure).

**Live:** https://yogesh-portfolio-omega-seven.vercel.app

## Sections

- **Hero** with a 3D scene (React Three Fiber) and resume download
- **Experience**, **projects** with live links, **skills**, certifications and achievements
- **GitHub activity**: contribution chart and streak
- **Contact** links

All content lives in one file, [`src/lib/data.ts`](src/lib/data.ts), so updating the site never means touching the components.

## Tech stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · Three.js / React Three Fiber · Framer Motion · GSAP

## Run locally

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
```

Deployed on Vercel; every push to `main` goes live.
